# P0.6 Protocol and Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze the Phase 1 wire encoding, version negotiation, bounded framing, message/correlation semantics, cancellation/retry behavior, replay handling, and serializer-independent canonical signing transcript.

**Architecture:** Protocol Buffers encode ordinary wire messages, but Cross-Lab never signs serializer output directly. Security objects reconstruct a separately specified canonical transcript before hashing/signing. Control protocol semantics stay transport-neutral and bounded.

**Tech Stack:** Markdown specification and ADR. Production crate versions are selected only when Phase 1 workspace implementation begins.

**Spec:** Master Architecture Sections 12-15, 37-44 plus P0.3-P0.5 specifications.

## Global Constraints

- Protocol types must not expose Quinn/Iroh/libp2p/platform types.
- Unknown/incompatible mandatory semantics fail closed.
- Control framing, collections, identifiers, and diagnostics have explicit bounds.
- Signed security objects use a canonical transcript independent of protobuf serialization order/implementation.
- Reconnect creates a fresh logical session and replay scope.
- Non-idempotent requests are never automatically retried by generic protocol code.
