# P0.6 — Protocol and Compatibility

**Status:** Completed  
**Phase:** Phase 0 — Architecture and Security Specification

## Objective

Freeze the Phase 1 control-plane wire contract, compatibility model, bounded framing, message lifecycle, replay/retry/cancellation behavior, and serializer-independent canonical signing rules.

## Scope

P0.6 defines version negotiation, feature compatibility, framing and collection limits, request/response/event semantics, sequencing, retries, cancellation, data-stream open metadata, typed protocol errors, and the canonical security transcript used for signatures and MACs.

## Decisions and Constraints

- Protocol/domain types remain independent from Quinn, Iroh, libp2p, BLE, USB, and platform-library types.
- Unknown mandatory semantics, unsupported versions, malformed security state, and oversized input fail closed.
- Control messages, identifiers, collections, diagnostics, and stream-open headers have explicit bounds.
- Reconnect creates a fresh logical session and replay scope.
- Generic protocol code never automatically retries non-idempotent requests.
- Signed or MACed security objects use an explicit canonical Cross-Lab transcript rather than serializer output.
- The v1 wire encoding and canonical signing profile are governed by ADR-0004.

## Acceptance Criteria

The protocol specification defines major/minor negotiation, required/optional feature handling, bounded framing, message envelopes, sequencing, correlation identifiers, retry classes, cancellation, events, capability advertisement, data-stream open headers, typed errors, canonical transcript framing, signed-object domains, compatibility rules, golden-vector obligations, and parser fuzzing targets.

## Verification

The specification was reviewed for downgrade resistance, parser/resource safety, replay handling, cross-version behavior, serializer-independent signing semantics, operation binding, and explicit failure behavior. Required golden-vector and fuzzing obligations are carried into Phase 1 implementation.

## Handoff

P0.6 provides the stable protocol contract consumed by secure-session authentication, the deterministic simulator, cross-language bindings, and the first Quinn transport milestone.
