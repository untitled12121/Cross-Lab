# P0.7 — Secure Sessions and Transport Contract

**Status:** Completed  
**Phase:** Phase 0 — Architecture and Security Specification

## Objective

Freeze secure logical-session authentication, channel binding, reconnect/revocation semantics, and the transport-neutral contract used by the simulator and the first real network transport.

## Scope

P0.7 defines session-authentication transcripts, peer credential/trust checks, session state, capability-negotiation timing, operation ownership, reconnect behavior, and the minimal secure transport interface required beneath Cross-Lab domain semantics.

## Decisions and Constraints

- Cross-Lab authentication remains independent from transport identity.
- Real untrusted transports must provide confidentiality and integrity before ordinary protected session traffic is accepted.
- Session authentication is fresh and bound to an opaque cryptographic channel-binding value supplied by the transport.
- Logical sessions own Cross-Lab identity, compatibility, capability, authorization, request/event, and operation state.
- Phase 1 does not use 0-RTT authorization, session resumption, or cross-transport authority migration.
- Reconnect creates a new session, requires fresh authentication, and does not inherit old operation identifiers.
- Concrete Quinn/Iroh/libp2p types remain outside the core/domain contracts.
- The deterministic in-memory transport is a test seam and does not claim production network security.

## Acceptance Criteria

The specification defines authentication hello/proof semantics, credential/trust/epoch/channel-binding validation, session state transitions, capability negotiation point, request/operation lifecycle ownership, close/cancellation behavior, revocation reaction, reconnect rules, and the required properties of secure transports, streams, metadata, and channel binding.

## Verification

The design was traced to threat-model requirements for identity substitution, replay, stale trust, channel confusion, operation misuse, revocation, reconnect, and resource safety. It was also checked to ensure no transport-library identifier becomes Cross-Lab identity authority.

## Handoff

P0.7 provides the session/transport contract used by the Core Simulator and later implemented first over the deterministic harness and then over Quinn.
